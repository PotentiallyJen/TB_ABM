# Project Documentation
This folder contains the code and datasets needed to run the Extended CuPy model.

## Running Project code
The following steps can be observed to reproduce results:

1. Navigate to https://www.kaggle.com/.
2. Import the 'cupy-extended-model' as a new Kaggle notebook
3. Add the 'pop-growth' and 'prerun-dataset' datasets as input
4. Click 'Run All'
